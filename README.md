This is my  project for Web Technologies course. It consists of a presentation of all updates of the video game Grand Theft Auto V - Online, categorized by year.
The files:
index.html - the main webpage
template.html - a template webpage that is going to be used for adding updates for each year
style.css - main css file used for everything
year.css - css file used to build onto the style.css file for the "year" pages
